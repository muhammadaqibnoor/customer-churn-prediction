# Dataset

Download the IBM Telco Customer Churn CSV and place it here as:

`data/Telco-Customer-Churn.csv`

Source used in the project:
https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Before redistributing the dataset, review the source repository's terms and licensing. The `.gitignore` intentionally excludes the CSV from Git commits.
